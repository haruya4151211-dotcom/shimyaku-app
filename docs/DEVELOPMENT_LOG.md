## 2. 重要な設計判断とその理由

### 地図の作り方
- **輪郭は現代の州・県（Natural Earth admin-1、約4,600区画）の組み合わせ**（`3997296`）。
  - 理由：手で打った多角形では形が粗く、隣り合う勢力の境界が噛み合わず、海へはみ出していた。ユーザーから「最重要・妥協不可」の品質指示があり、仕組みの上でずれが起きない方式に切り替えた。
  - 境界は共有して簡略化するため、隣接する勢力の境界は必ず同じ線になる。州・県の途中を通る国境（ナーエ川など）は川筋に沿った線で分割している。
  - 限界（ユーザーに報告済み）：当時の国境が州・県の内側を細かく出入りする箇所は近似。小さな属国・飛び地・係争地は省略。1942年のドイツは占領地を含めて描いている。
- **存続期間ベースのデータ**（`6f37b66`）。
  - 理由：全世界化（未実装56%の追加）に向けて、年代ごとの固定スナップショット定義のままではデータが肥大化・破綻するため（ユーザーの改修指示）。
  - 勢力ごとに `life`（存続期間）と `shapes`（期間ごとの形）を持ち、`series.js` の年から地図を自動で組み立てる。
  - 移行時、26勢力で史実の存続期間を採用（唐 618〜907 など）。それ以外は「地図に描いている年代の範囲」を存続期間にしている（例：フランス王国は962年の地図で描くため、987年の建国とずれる）。
- **年代を変えてもカメラを動かさない**【決定】（ユーザーの要望：日本の古代〜現代の変遷を追いたい）。自動で動くのは地図タブを最初に開いたとき・地域移動・リセット・検索結果の選択だけ。
- **地図の横方向は無限ループ**、カメラは「中心＋倍率」で管理（`214d4f7`）。最大ズーム14倍（`c4a0839`。殷のような小さな勢力を大きく拡大したいという要望）。

### カードとデータ
- **答えの漏れを出さない**：カードの答えが同じ時代の地図の文字や他カードに出ないことを `npm run check` で全数検査する。勢力名・都市名は答えにできない。
- **地理名と答えが重なったら、カードの言い換えを優先**【決定】（ユーザーの判断指針、地理ステップ1）。地理名を隠すのは言い換えが困難な場合だけ（`hideIn`。例：シュレジエンは絶対王政期の地図で非表示）。
- **1勢力2問以上**を目安に（タップ時にスカスカにしないため）。ただし優先度2・3では1問の勢力もある（後述）。
- **絶対王政の時代は旧「三十年戦争」の試作カードと統合し厳選**【決定】（ユーザーが選択）。
- **ヴァルダナ朝の存続期間を650年まで延長**【決定】（ユーザーが承認）。

### 画面の表示
- **ズームの5段階（Tier）**：1.0 / 1.6 / 2.2 / 3.5 / 5.0 倍（ユーザーの指定）。勢力名も面積に応じてこの段階で出す。
- **文字の重なりを政治／地理の2層で判定**：地理の文字は勢力名と重なっても消さず半透明（「寄っても地理が見えない」という問題への対応）。
- **地理の文字の縁取りは濃紺**：ユーザーの例示は「白フチ等」だったが、地図の地色が暗く白フチだと明るい文字が読みにくくなるため（報告済み）。
- **河川は引きでは控えめ**（ユーザー指示：引きでは勢力の塗りと国名が主役）。線は名前より1段早い倍率から淡く出し、寄るほど太く濃く。

### 検索
- 索引は全時代の地図（勢力・都市・地理）と全カード。表記ゆれ（カタカナ／ひらがな、全角／半角、ヴァ／バ、中黒・＝の有無、一部の旧字体）を吸収。
- 地図の要素を選んだら「いま見ている年の地図にあればその年のまま、なければ最も近い年」へ移る。カードは「その勢力が地図に出る年のうちカードの年に最も近い年」。
- **カードを選んだときは、勢力の詳細シートの先頭にそのカードを出す**（「解答を見る」「このカードを解く」）。地図上にクイズ専用のモーダルがないため、また自動で学習画面へ移ると年代移動・強調が見えなくなるため、この形にした。学習画面へ直接飛ばす形にも変えられる旨を報告済みで、ユーザーの回答はまだない。

### 年代切り替えの演出
- 変化する勢力だけクロスフェード、変わらない勢力はそのまま。**カメラは一切動かさない**【決定】（ユーザーの絶対条件）。
- 演出時間：0.72秒 → **0.45秒**【決定】（ユーザーが「もう少し短縮」と要望）。
- 演出は1つずつ順番に再生し、演出中に届いた年は待たせて次の演出で追いかける。ドラッグ中も瞬時の切り替えはせず、指を離した年へ必ずクロスフェードで着地する（`c3db76b`）。

## 3. 過去に発生した問題と解決方法

| 問題 | 原因 | 解決 |
|---|---|---|
| カード画像が見切れる（c40 ルター） | CSS ではなく、元画像自体が16:9に切り抜かれたものだった | 全体が写った画像に差し替え（表示は object-contain で検証済み） |
| `Unable to preventDefault inside passive event listener` が大量発生 | React の `onWheel`/`onTouchStart` は passive | wheel はネイティブリスナー（`passive:false`）に、スライダーのつまみは `touch-action: none` に |
| `Cannot update a component (MapView) while rendering ... (RegionDetailSheet)` | 関数型の setState の中で親の setState を呼んでいた | ドラッグ量を ref に持ち、指を離したハンドラーで判定 |
| 回答記録が保存されない（`storage save failed ... 'set'`） | `window.storage`（Claude アーティファクト環境専用）を前提にしていた | `appStorage`：window.storage → localStorage → メモリの順にフォールバック |
| 年代を変えると地図が勝手にヨーロッパへ移る | 時代区分が変わるたびに初期表示へ移していた | 自動移動は地図タブを開いた最初だけに |
| 勢力ポリゴンがカクカク・海へはみ出す・境界が噛み合わない | 手描きの十数点の多角形 | Natural Earth の州・県の組み合わせへ全面作り直し |
| 答えの漏れ（ナイル、ウマイヤ朝、カルタゴ、オーストリアなど多数） | 地図の文字・他カードの本文に答えが出ていた | `npm run check` で検出し、カードの答え・本文を言い換え（例：c57 の答えは「ウマイヤ朝」→ 勢力名「後ウマイヤ朝」と重なるため「ピレネー」→ 地理名「ピレネー山脈」と重なるため「トゥール・ポワティエ間」。c20 は「国民公会」、c33 は「フェニキア人」へ） |
| 地理名が勢力名に負けて消える | 重なり判定が1層で地理が最下位 | 政治／地理の2層に分離 |
| 河川が引きの画面で主張しすぎ | 線が太く明るかった | 倍率に応じて太さ・濃さを滑らかに補間 |
| 連続ドラッグでカクつく（スマホ相当で約30fps） | 動きごとに地図全体と App 全体を再描画 | rAF でまとめる、`useDeferredValue`、時代同期をドラッグ終了時に（本番ビルドでスマホ相当60fps） |
| クロスフェードが一切再生されない（ユーザーが動画で発見） | 演出を「表示中の年と完全一致」で描いていたため年が少し動くと消えた。高速時は即時切替で着地演出なし | 演出を勢力図（スナップショット）に結び付け、1つずつ順番に再生する方式へ |
| 地図のパンで `Ignored attempt to cancel a touchmove event with cancelable=false` | スクロール開始後の取り消せないイベントで preventDefault | `if (e.cancelable)` を付けた |
| `git push` が終わらない | 認証待ちのように見えて実際は完了していた | `GIT_TERMINAL_PROMPT=0` とタイムアウトを付けて実行 |
| 長い作業の途中で中断（PC のスリープ、5時間の利用上限、ネットワークエラー） | — | 途中のコード状態を確認してからやり直した |
| Wikimedia の 429（アクセス制限）、960px 以外のサムネイルがエラー | — | 間隔をあけて取得、常に960px（または原寸が960px以下なら原寸） |
